INTRODUCTION TO SQL FOR DATA ANALYSIS
Topics: Database Concepts, Tables, Keys, SELECT, WHERE, ORDER BY, and LIMIT

OBJECTIVE
Understand how relational databases store information and learn to retrieve, filter, sort, and limit records using SQL. Use a student database as the practical dataset.

A. SET UP THE SQL ENVIRONMENT
[ ] Install or open MySQL Community Server and MySQL Workbench (or use the SQL environment provided by your trainer).
[ ] Connect to the local MySQL server.
[ ] Create a folder named SQL_Data_Analysis inside your main training folder.
[ ] Create a file named day31_sql_practice.sql.
[ ] Create a text file named day31_notes.txt.
[ ] Write down the database name, connection method, and SQL tool used.
[ ] Do not share or include database passwords in submitted files.

C. CREATE A DATABASE AND TABLES
[ ] Create a database named student_analysis_db.
[ ] Select the database using USE.
[ ] Create a table named students with these columns:
    - student_id: INT, PRIMARY KEY, AUTO_INCREMENT
    - student_name: VARCHAR(100)
    - age: INT
    - city: VARCHAR(60)
    - course_id: INT
    - marks: DECIMAL(5,2)
    - attendance: DECIMAL(5,2)
    - fee_status: VARCHAR(20)
[ ] Create a table named courses with these columns:
    - course_id: INT, PRIMARY KEY, AUTO_INCREMENT
    - course_name: VARCHAR(100)
    - course_fee: DECIMAL(10,2)
    - instructor: VARCHAR(100)
[ ] Use SHOW DATABASES to list databases.
[ ] Use SHOW TABLES to list tables in the selected database.
[ ] Use DESCRIBE students and DESCRIBE courses to inspect table structures.

[ ] Display students from a chosen city.
[ ] Display students whose fee_status is Paid.
[ ] Display students whose fee_status is Pending.
[ ] Use >, <, >=, and = operators.
[ ] Use AND to filter students who scored at least 60 and have attendance of at least 75%.
[ ] Use OR to filter students from either of two cities.
[ ] Use NOT to exclude a selected fee status.
[ ] Use BETWEEN to find students with marks in a specified range.
[ ] Use IN to filter students from a list of cities.
[ ] Use LIKE to find student names beginning with a selected letter.
[ ] Use LIKE to find student names containing a chosen character sequence.
[ ] Use IS NULL to check for missing values if any are present.
