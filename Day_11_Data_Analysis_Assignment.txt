3. TWO-HOUR PLAN


- Open Student_Data and check the data.
- Create a worksheet named Day11_Chart_Analysis.
- Review your Day 10 course summary and KPI results.


Write one suitable use for each chart:
- Column chart: compare values across categories, e.g. students by course.
- Bar chart: compare categories with long labels, e.g. students by city.
- Line chart: show trends over time, e.g. enrollments by month.
- Pie chart: show parts of a whole, e.g. Paid vs Pending fees, using only a few categories.
- Scatter chart: explore the relationship between two numeric variables, e.g. attendance and marks.


On Day11_Chart_Analysis, create a table:
Course | Student Count

List every course in Student_Data. Use COUNTIF. If the course name is in A2:
=COUNTIF(Student_Data!$G$2:$G$31,A2)

Create a column chart titled “Students by Course”.

- Student Count must appear on the vertical axis.
- Add data labels if helpful.

TASK C: MARKS DISTRIBUTION
Create a table:
Marks Band | Number of Students
Below 40
40–59
60–79
80–100

Use these formula examples:
Below 40:
=COUNTIF(Student_Data!$J$2:$J$31,"<40")

40–59:
=COUNTIFS(Student_Data!$J$2:$J$31,">=40",Student_Data!$J$2:$J$31,"<60")

60–79:
=COUNTIFS(Student_Data!$J$2:$J$31,">=60",Student_Data!$J$2:$J$31,"<80")

80–100:
=COUNTIFS(Student_Data!$J$2:$J$31,">=80",Student_Data!$J$2:$J$31,"<=100")

Create a bar or column chart titled “Student Marks Distribution”.
Check that the bands do not overlap and that all valid marks are counted.
