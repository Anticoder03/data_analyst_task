TASK B: CLEAN TEXT DATA
In Day14_Cleaned_Data, clean the text fields using these functions:

TRIM — remove unnecessary spaces:
=TRIM(B2)

PROPER — convert text into proper case:
=PROPER(TRIM(F2))

UPPER — convert text into uppercase:
=UPPER(TRIM(A2))

LOWER — convert text into lowercase:
=LOWER(TRIM(B2))

Apply suitable functions to First_Name, Last_Name, City, Course, and Fee_Status. Keep the cleaned values consistent with the original information.

TASK C: HANDLE MISSING AND DUPLICATE DATA
On your practice dataset:
1. Identify blank Student_ID cells.
2. Identify duplicate Student_ID records.
3. Identify missing Marks.
4. Identify missing Attendance_Percentage.
5. Identify invalid Fee_Status values.

Use Filter, Conditional Formatting, Remove Duplicates, COUNTIF, COUNTBLANK, IF, or IFERROR.

Example duplicate check:
=COUNTIF($A$2:$A$31,A2)

A result greater than 1 means that the Student_ID appears more than once in the range.

Important:
- Never invent missing student information.
- Do not automatically replace missing marks with zero.
- Do not delete records without documenting the reason.
- Use Remove Duplicates only on your practice copy.
- Record every correction in Day14_Cleaning_Report.

TASK D: DATA VALIDATION
Apply Excel Data Validation to prevent incorrect future entries:
1. Marks: whole numbers between 0 and 100.
2. Age: whole numbers between 15 and 60.
3. Attendance_Percentage: decimal values between 0 and 100 if stored as whole numbers, or between 0 and 1 if stored as true Excel percentages.
4. Fee_Status: dropdown containing Paid and Pending.
5. Gender: dropdown using the categories supported by your practice dataset.
6. Course: dropdown using the available course names.

Test each rule with valid and invalid values in a separate practice area.

TASK E: CONDITIONAL FORMATTING
Apply these rules to your cleaned dataset:
1. Marks below 40 — highlight as a warning.
2. Marks greater than or equal to 80 — highlight as high performance.
3. Attendance below 75 — highlight for review.
4. Pending fee status — highlight for follow-up.
5. Duplicate Student_ID values — highlight duplicate records.
6. Blank Student_ID cells — highlight missing values.

Keep the worksheet readable and avoid excessive formatting.
