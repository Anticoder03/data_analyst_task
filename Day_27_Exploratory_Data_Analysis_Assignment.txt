Topics: Descriptive Statistics, Data Distributions, Correlation, and Outlier Detection

OBJECTIVE
Explore a dataset systematically, understand its structure and patterns, identify unusual values, and communicate findings using statistical summaries and Pandas.

D. ANALYSE DATA DISTRIBUTIONS

[ ] Create a correlation matrix using corr().
[ ] Display the correlation between marks and attendance.
[ ] Identify the pair of numeric variables with the strongest positive correlation.
[ ] Identify the pair with the strongest negative correlation, if one exists.

[ ] Remember: correlation does not prove that one variable causes another.
[ ] Save the correlation matrix as day27_correlation_matrix.csv.

F. DETECT OUTLIERS
[ ] Select the marks column for outlier analysis.
[ ] Calculate Q1 and Q3 using quantile().
[ ] Calculate the interquartile range (IQR): Q3 - Q1.
[ ] Calculate the lower boundary: Q1 - 1.5 * IQR.
[ ] Calculate the upper boundary: Q3 + 1.5 * IQR.
[ ] Identify records below the lower boundary or above the upper boundary.
[ ] Display outlier records with student_id and marks.
[ ] Repeat the IQR method for attendance.
[ ] Count the outliers in each selected column.
[ ] Save identified outliers as day27_outliers.csv.
[ ] Do not automatically delete outliers. Explain why an unusual value should be investigated before changing or removing it.
