============================================================
TASK 3 — FORMAT THE DATASET
============================================================

1. Make the header row bold and apply a background color.
2. Adjust column widths so all content is readable.
3. Format Enrollment_Date as DD-MM-YYYY.
4. Format Attendance_Percentage with a percent sign. If values are
   entered as 92, 88, etc., convert them to actual percentage values
   correctly; do not accidentally display 9200%.
5. Format Marks as whole numbers.
6. Convert the dataset to an Excel Table using Ctrl+T.
7. Enable filters and freeze the header row.
8. Apply conditional formatting to highlight marks below 40.
9. Use consistent capitalization for names, cities, courses and fee status.

============================================================
TASK 4 — DATA QUALITY INVESTIGATION 
============================================================

In the Data_Quality_Report worksheet, create these headers:

Issue_ID | Issue_Type | Student_ID | Description | Action_Taken

Inspect the dataset for:
- Duplicate Student IDs.
- Missing values.
- Incorrect data types.
- Attendance values outside 0–100.
- Marks outside 0–100.
- Ages that are zero, negative or implausible for this dataset.
- Inconsistent category names, such as "python", "Python " and "PYTHON".
- Fee statuses other than "Paid" or "Pending".

Document every issue actually found. Do not deliberately change the
provided sample records to create errors. Any added records should be
checked honestly, and the report should reflect the issues found.
