DAY 28 — DATA VISUALIZATION WITH MATPLOTLIB
Topics: Line Charts, Bar Charts, Histograms, Scatter Plots, and Chart Customization

OBJECTIVE
Learn to communicate data insights visually using Matplotlib. Create clear, correctly labelled charts and choose an appropriate chart type for different analytical questions.

B. MATPLOTLIB FUNDAMENTALS
[ ] Create your first chart using plt.plot().
[ ] Set figure size using plt.figure(figsize=(...)).
[ ] Add a title using plt.title().
[ ] Add x-axis and y-axis labels using plt.xlabel() and plt.ylabel().
[ ] Add grid lines using plt.grid().
[ ] Display the chart using plt.show().
[ ] Save a chart using plt.savefig() before closing the figure.
[ ] Use clear titles and labels so viewers can understand each chart.
