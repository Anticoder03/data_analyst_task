Topic: Excel Lookup Formulas — XLOOKUP and VLOOKUP
Duration: 2 hours | Level: Beginner

1. OBJECTIVE
Learn to retrieve a student's details using Student_ID, use exact-match lookups, and handle IDs that are not found.

3. TWO-HOUR PLAN

0–15 MINUTES — REVIEW
- Open Student_Data.
- Manually find three Student_ID values.
- Review IFERROR and the Day 8 summary tables.

15–35 MINUTES — LEARN THE FORMULAS

VLOOKUP syntax:
=VLOOKUP(lookup_value, table_array, column_index_number, FALSE)

Examples, assuming records are in rows 2–31:
First name:
=VLOOKUP(A2,Student_Data!$A$2:$K$31,2,FALSE)

Course:
=VLOOKUP(A2,Student_Data!$A$2:$K$31,7,FALSE)

Marks:
=VLOOKUP(A2,Student_Data!$A$2:$K$31,10,FALSE)

Notes:
- The lookup column must be the first column in the selected VLOOKUP range.
- FALSE requests an exact match.
- The column index counts from the start of the selected table range.

If your Excel version supports XLOOKUP:
First name:
=XLOOKUP(A2,Student_Data!$A$2:$A$31,Student_Data!$B$2:$B$31,"ID not found")

Course:
=XLOOKUP(A2,Student_Data!$A$2:$A$31,Student_Data!$G$2:$G$31,"ID not found")

Marks:
=XLOOKUP(A2,Student_Data!$A$2:$A$31,Student_Data!$J$2:$J$31,"ID not found")

XLOOKUP separates the lookup column from the return column. If XLOOKUP is unavailable, complete the assignment using VLOOKUP.

35–75 MINUTES — BUILD A STUDENT LOOKUP TOOL
Create a worksheet named Day9_Student_Lookup.

Create this form:
A1: STUDENT LOOKUP TOOL
A3: Enter Student ID
B3: Type a valid ID, for example ST001
A5: First Name
A6: Last Name
A7: City
A8: Course
A9: Attendance
A10: Marks
A11: Fee Status

Enter the formulas in column B next to the corresponding labels. For VLOOKUP, assuming the entered ID is in B3:

First Name:
=IFERROR(VLOOKUP($B$3,Student_Data!$A$2:$K$31,2,FALSE),"ID not found")

Last Name:
=IFERROR(VLOOKUP($B$3,Student_Data!$A$2:$K$31,3,FALSE),"ID not found")

City:
=IFERROR(VLOOKUP($B$3,Student_Data!$A$2:$K$31,6,FALSE),"ID not found")

Course:
=IFERROR(VLOOKUP($B$3,Student_Data!$A$2:$K$31,7,FALSE),"ID not found")

Attendance:
=IFERROR(VLOOKUP($B$3,Student_Data!$A$2:$K$31,9,FALSE),"ID not found")

Marks:
=IFERROR(VLOOKUP($B$3,Student_Data!$A$2:$K$31,10,FALSE),"ID not found")

Fee Status:
=IFERROR(VLOOKUP($B$3,Student_Data!$A$2:$K$31,11,FALSE),"ID not found")

Alternatively, use XLOOKUP for each field. Example for First Name:
=XLOOKUP($B$3,Student_Data!$A$2:$A$31,Student_Data!$B$2:$B$31,"ID not found")

75–95 MINUTES — TEST YOUR TOOL
Test at least five IDs and compare each result against Student_Data:
- Four valid Student_ID values.
- One invalid ID, such as ST999.
The invalid ID should show “ID not found” instead of an error.

Create a worksheet named Day9_Test_Log with columns:
Tested Student_ID | Expected Result | Actual Result | Pass/Needs Fix

Record all five tests.

95–110 MINUTES — FORMAT AND DEBUG
- Add clear labels, borders, and readable formatting.
- Format attendance and dates appropriately.
- Make sure formulas refer to the input cell $B$3.
- Use FALSE for exact-match VLOOKUP.
- Check that the lookup range includes every student.
- Confirm IDs match the source data exactly.

110–120 MINUTES — REFLECTION
Create a worksheet named Day9_Reflection and answer:
1. What is a lookup formula used for?
2. What does FALSE mean in VLOOKUP?
3. Why must Student_ID be the first column in the VLOOKUP table range?
4. Give one advantage of XLOOKUP over VLOOKUP.
5. Why use IFERROR or XLOOKUP's “if not found” argument?
6. Give one workplace situation where lookup formulas would be useful.
