VLOOKUP syntax:
=VLOOKUP(lookup_value, table_array, column_index_number, FALSE)

Examples, assuming records are in rows 2–31:
First name:
=VLOOKUP(A2,Student_Data!$A$2:$K$31,2,FALSE)

Course:
=VLOOKUP(A2,Student_Data!$A$2:$K$31,7,FALSE)

Marks:
=VLOOKUP(A2,Student_Data!$A$2:$K$31,10,FALSE)

Notes:
- The lookup column must be the first column in the selected VLOOKUP range.
- FALSE requests an exact match.
- The column index counts from the start of the selected table range.

If your Excel version supports XLOOKUP:
First name:
=XLOOKUP(A2,Student_Data!$A$2:$A$31,Student_Data!$B$2:$B$31,"ID not found")

Course:
=XLOOKUP(A2,Student_Data!$A$2:$A$31,Student_Data!$G$2:$G$31,"ID not found")

Marks:
=XLOOKUP(A2,Student_Data!$A$2:$A$31,Student_Data!$J$2:$J$31,"ID not found")

XLOOKUP separates the lookup column from the return column. If XLOOKUP is unavailable, complete the assignment using VLOOKUP.
